Context Gateway connects to data sources across social, health, productivity, entertainment, and commerce. Users connect sources once and permission what they share. Your application queries the result through a single API.

## Available now

| Source | Category | Key data |
|---|---|---|
| Instagram | Social | Profile, posts, engagement metrics |
| iCloud Notes | Productivity | Note content, folders, timestamps |
